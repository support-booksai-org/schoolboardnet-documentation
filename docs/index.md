# schoolboard.net Documentation

Welcome to the official documentation source for **schoolboard.net**.

This site is generated from Markdown using MkDocs and Material for MkDocs. The repository is designed to support customer manuals, internal technical documentation, Knowledge Base articles, and BooksAI ingestion from a consistent documentation source.

!!! note "Documentation status"
    This documentation site is in early foundation stage. Content is being added and revised as part of the schoolboard.net Documentation Suite project.

## Documentation areas

- **Volume 0 — Documentation Standards** defines the rules used to create and maintain all documentation.
- **Administrator Topics** will become the source for the Administrator Training Guide and related Knowledge Base articles.
- **Accessibility** will collect WCAG 2.1 AA publishing guidance.
- **Content Authoring** will document Word, Google Docs, HTML cleanup, and AI-assisted conversion workflows.
