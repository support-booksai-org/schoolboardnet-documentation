# Getting Started

## Quick Summary

This section explains what schoolboard.net is and how to use this documentation.

Start here if you are new to schoolboard.net.

You will learn:

- What schoolboard.net does.
- Why accessibility matters.
- Why schoolboard.net uses web pages instead of relying only on PDFs.
- The basic words used in the system.
- How to get help.

## Who Should Read This Section

This section is written for:

- District Administrators
- Group Administrators
- Board Clerks
- Administrative Assistants
- IT staff
- Anyone who helps prepare board meeting materials

## Plain Language Standard

This documentation is written in simple language.

Our goal is clear, simple, step-by-step documentation so a reader can understand the instructions.

That means:

- Short sentences.
- Clear steps.
- Common words.
- No unexplained technical terms.
- Examples when they help.
