# Documentation Conventions

## Quick Summary

This page explains how to read and use the schoolboard.net documentation.

## Plain Language

We write in plain language.

That means we try to use words most people understand.

When a technical word is needed, we explain it.

## Steps

Procedures are written one step at a time.

Example:

1. Open the Users page.
2. Select Add User.
3. Enter the user's information.
4. Save the user.

## Menu Paths

Menu paths show where to go.

Example:

```text
Administration → Users → Add User
```

This means:

1. Open Administration.
2. Select Users.
3. Select Add User.

## Buttons and Fields

Button names and field names are shown in bold.

Example:

Select **Save**.

Enter the user's email address in **Email**.

## Notes and Warnings

This documentation uses special sections.

### Tip

A tip gives you a helpful shortcut.

### Best Practice

A best practice tells you the recommended way to do something.

### Accessibility Note

An accessibility note explains how a choice affects people using assistive technology.

### Administrator Note

An administrator note gives extra information for users with management responsibilities.

### Warning

A warning tells you about something that could cause confusion or problems.

## Screenshot Placeholders

Some pages include screenshot placeholders.

Screenshots will be captured from `demo10.schoolboard.net` after the workflow is reviewed.
