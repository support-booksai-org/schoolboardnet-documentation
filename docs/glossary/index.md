# Glossary

## Quick Summary

This glossary explains important schoolboard.net words in plain language.

## Initial Terms

### Accordion Agenda

An agenda that opens and closes in sections so the page is easier to read.

### Agenda Item

One topic or action listed on an agenda.

### Agenda Section

A major part of an agenda, such as Consent Agenda or Action Items.

### Board Clerk

A person who helps prepare, publish, and manage board meeting materials.

### District Administrator

A user with broad access to manage schoolboard.net for a district.

### Expandable HTML

Web content that opens when selected. It is useful for long text that should stay easy to find but not crowd the page.

### Group

A collection of users and content, often used for boards, committees, or departments.

### Group Administrator

A user who can manage certain content or users inside a group.

### Permission

A rule that controls what a user can see or do.

### Private File

A file that is limited to users with the correct permission.

### Public File

A file that can be viewed by people allowed to see the public agenda.

### Revision

A saved version of content that helps track changes.

### User

A person who can sign in to schoolboard.net.

### WCAG

Web Content Accessibility Guidelines. These are standards for making websites and digital content easier for people with disabilities to use.

### Word Junk

Extra formatting that can come from Microsoft Word when text is pasted into a web editor.
