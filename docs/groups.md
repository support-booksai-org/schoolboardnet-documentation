# Groups

The Groups list shows group ID, name, type, publication status, owner, and available operations.

![Groups page with Add group, group list columns, and Operations controls identified.](assets/screenshots/SB-DST-012-groups-annotated.png){ .doc-screenshot }

*Figure SB-DST-012. Groups list.*

## Review a group

1. Confirm the group name and type.
2. Open the group's operation menu or open the group.
3. Select **Members**.
4. Review existing members before adding another user.

The screenshot includes examples of **Public**, **Board Groups**, **District Groups**, and **No Private File Access**. Do not change a group's type merely to solve one person's access problem.

!!! note "Deferred scope"
    The Add Group and Edit Group forms are not included in this review draft. Group creation and type-selection procedures will be documented separately when that scope is approved.
