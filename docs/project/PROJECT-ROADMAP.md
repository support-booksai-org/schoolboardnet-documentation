# Project Roadmap

## Phase 1 — Foundation

- Build MkDocs documentation preview site.
- Establish repository structure.
- Create Documentation Standards Manual.
- Define screenshot, Markdown, metadata, accessibility, and review standards.

## Phase 2 — Administrator Documentation

- Build administrator topics for users, groups, permissions, agendas, notifications, revisions, publishing, search, and printing.
- Create matching Knowledge Base articles.

## Phase 3 — Content Authoring and Accessibility

- Build accessible content authoring guide.
- Document Microsoft Word and Google Docs best practices.
- Document AI-assisted HTML conversion workflows.

## Phase 4 — Technical and Deployment Documentation

- Build Deployment & QA Manual.
- Build Technical Administrator & Developer Reference.
