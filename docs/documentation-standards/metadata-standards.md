# Metadata Standards

Every Markdown topic should begin with YAML front matter.

```yaml
title: Add User
status: Draft
version: 1.0.0
author: schoolboardnet, LLC
audience:
  - District Administrator
  - Board Clerk
wcag: "2.1 AA"
tags:
  - users
  - administration
```

Metadata supports publishing, search, release tracking, and BooksAI ingestion.
