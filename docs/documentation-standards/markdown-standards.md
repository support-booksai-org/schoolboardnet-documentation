# Markdown Standards

Markdown files must be clear, accessible, and easy to convert to HTML, PDF, and Knowledge Base content.

## Heading rules

- Use one `#` heading per page.
- Do not skip heading levels.
- Use descriptive headings.
- Avoid vague headings such as “More” or “Information.”

## Lists

Use numbered lists for procedures. Use bullets for unordered supporting information.

## Links

Use meaningful link text. Do not use “click here.”

## Images

Every image must include descriptive alternate text.
