# Screenshot Standards

All screenshots must be taken from `demo10.schoolboard.net` unless otherwise specified.

## Screenshot naming

Use stable IDs:

```text
SB-ADM-001-dashboard-home.png
SB-USR-001-users-list.png
SB-USR-002-add-user-form.png
```

## Screenshot folders

| Folder | Purpose |
|---|---|
| `docs/assets/screenshots/raw/` | Original screenshots. |
| `docs/assets/screenshots/annotated/` | Screenshots with callouts. |
| `docs/assets/screenshots/approved/` | Final screenshots used in published documentation. |
