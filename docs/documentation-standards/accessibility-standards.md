# Accessibility Standards

schoolboard.net documentation must support WCAG 2.1 AA practices.

## Requirements

- Use semantic headings.
- Provide alternate text for meaningful images.
- Avoid color-only meaning.
- Use descriptive links.
- Use plain language whenever possible.
- Keep procedures clear and sequential.
- Identify warnings before irreversible actions.
