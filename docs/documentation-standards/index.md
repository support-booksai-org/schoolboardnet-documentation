# Documentation Standards Manual

The Documentation Standards Manual defines how schoolboard.net documentation is written, reviewed, versioned, published, and maintained.

## Purpose

The purpose of this manual is to ensure that every schoolboard.net document, Knowledge Base article, training guide, and AI source article follows a consistent structure and supports WCAG 2.1 AA accessibility expectations.

## Applies to

- Customer-facing documentation
- Internal technical documentation
- Knowledge Base articles
- BooksAI training corpus files
- Release notes
- Quick reference guides
- Video scripts
