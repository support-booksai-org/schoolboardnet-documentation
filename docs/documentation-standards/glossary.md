# Glossary

## Accordion Agenda

The primary schoolboard.net agenda format used to publish accessible, expandable board meeting content.

## Expandable HTML

A content block that displays accessible HTML content in an expandable section. Expand text should usually begin with “Read …” for screen reader clarity.

## Public File

A file intended for public access.

## Private File

A file intended only for authorized users or groups.
