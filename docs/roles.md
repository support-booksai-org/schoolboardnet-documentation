# Roles and access

Review site roles and group memberships separately. Use the least access required for the person's assignment.

## Role guidance

- **District Admin** is for approved district-level administration.
- **Group Admin** is for approved group-management functions allowed by site configuration.
- An ordinary Board Member generally needs the correct group membership, not a site-wide administrator role.

## Least-access sequence

1. Start with the ordinary user account.
2. Add only required group memberships.
3. Add Group Admin only when the person must manage the group.
4. Add District Admin only when district-wide administration is required.
5. Test with the user's own account; never share administrator credentials.

!!! note "Reviewer confirmation"
    Role scope can be modified by site configuration. Confirm that these descriptions match production permissions.
