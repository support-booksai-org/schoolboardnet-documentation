# schoolboard.net Documentation Suite

# Screenshot Index

**Document Version:** 1.0\
**Last Updated:** July 2026

---

## Purpose

This document serves as the master inventory of all approved screenshots used throughout the schoolboard.net Documentation Suite.

Each screenshot is assigned a permanent identifier (ID). Documentation pages should reference the screenshot ID rather than the filename whenever possible.

Example:

> See **Screenshot SB-PUB-001**.

This allows screenshots to be replaced or updated without requiring changes throughout the documentation.

---

# Screenshot Status

| Status   | Meaning                                    |
| -------- | ------------------------------------------ |
| Planned  | Screenshot identified but not yet captured |
| Draft    | Initial capture awaiting review            |
| Approved | Approved for documentation use             |
| Archived | No longer used but retained for history    |

---

# Naming Standard

```
SB-ROLE-###-description.png
```

Examples:

```
SB-PUB-001-home-page-clean.png
SB-PUB-001-home-page-navigation-annotated.png
SB-BRD-003-change-password.png
SB-GRP-008-user-permissions.png
```
