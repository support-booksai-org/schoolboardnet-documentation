# Users Screenshot Source

## Purpose

This folder stores the editable Snagit source file for the **Users** screenshots.

## Source File

`users-overview.snagx`

## PNG Exports

Export finished PNG files to:

`assets/screenshots/users`

Suggested exports:

- `users-list.png`
- `users-add.png`
- `users-edit.png`
- `users-reset-password.png`

## Workflow

1. Capture the base screen in Snagit.
2. Save the editable source as `users-overview.snagx`.
3. Duplicate/annotate inside Snagit as needed.
4. Export final PNG files using the names above.
5. Run sbDocs inventory/validation before publishing.
