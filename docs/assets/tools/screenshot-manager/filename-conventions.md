# Screenshot Filename Conventions

## Recommended format

```text
<feature>-<screen>.png
```

Use lowercase letters and hyphens. Avoid spaces, underscores, dates, and random numbers.

## Good examples

```text
dashboard-home.png
dashboard-search.png
dashboard-login.png
users-list.png
users-add.png
users-edit.png
users-reset-password.png
groups-list.png
groups-add.png
groups-add-members.png
meetings-event-agenda.png
meetings-accordion-agenda.png
notifications-signup.png
settings-permissions.png
```

## Avoid

```text
Screen Shot 2026-07-02 at 1.22.44 PM.png
SB-ADM-001-dashboard-v01.png
new-dashboard-final-final.png
image1.png
```

## When to use versions

Only use versions when the same screenshot must remain available for history or comparison.

```text
dashboard-home-v1.png
dashboard-home-v2.png
```

For normal updates, replace the old screenshot with the same filename.

## Feature folder examples

```text
assets/screenshots/dashboard/dashboard-home.png
assets/screenshots/users/users-list.png
assets/screenshots/groups/groups-add-members.png
assets/screenshots/meetings/meetings-accordion-agenda.png
```
