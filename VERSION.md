# Documentation Version

Current documentation version: **1.0.0-draft**

## Versioning Format

Documentation versions should generally follow the related schoolboard.net software release.

Example:

```text
schoolboard.net application: 2.1.0
Documentation suite: 2.1.0
Knowledge Base: 2.1.0
```

## Version Stages

- `draft` — Working material not yet approved.
- `review` — Ready for review.
- `approved` — Approved but not yet published.
- `published` — Released to customers or internal users.
