# Contributing to the schoolboard.net Documentation Suite

## General Guidelines

- Use clear, direct language.
- Write for administrators, clerks, and district staff who may not be technical.
- Use official terminology from `00-style-guide/terminology.md`.
- Follow the chapter structure in `templates/chapter-template.md`.
- Use screenshots from `demo10.schoolboard.net` unless otherwise directed.
- Do not introduce undocumented product names, fields, or workflows without review.

## Accessibility Requirements

Documentation should support WCAG 2.1 AA principles:

- Use logical headings.
- Use descriptive links.
- Avoid instructions based only on color or position.
- Provide meaningful alt text for screenshots.
- Use simple tables with clear headers.
- Avoid unnecessary jargon.

## Review Process

Recommended review sequence:

1. Draft
2. Product review
3. Technical review
4. Accessibility review
5. Final approval
6. Publication
