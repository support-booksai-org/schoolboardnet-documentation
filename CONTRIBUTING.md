# Contributing

This repository is maintained by schoolboardnet, LLC.

## Contribution rules

1. Use Markdown for source content.
2. Store reusable articles in `content/`.
3. Do not duplicate the same topic across manuals.
4. Use YAML front matter on every source article.
5. Use approved terminology from `00-documentation-standards/15-glossary.md`.
6. Add screenshot placeholders when screenshots are required.
7. Maintain WCAG 2.1 AA writing and structure practices.
8. Update related collection files when adding new source articles.
