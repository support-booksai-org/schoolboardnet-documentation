# Troubleshooting Authoring Problems

## Pasted text has the wrong font, size, or spacing

Remove formatting or paste the affected section as plain text. Reapply only the headings, lists, links, tables, and emphasis that carry meaning.

## Extra blank space appears

Look for empty paragraphs, repeated line breaks, paragraph spacing copied from the source, or layout tables. Remove the unnecessary elements and review the saved page.

## A list restarts or indents incorrectly

Remove the broken list formatting and recreate the list using the editor's numbered or bulleted list control. Do not type the numbers, bullets, tabs, or spaces manually.

## A table does not fit on a phone

Remove fixed widths and unnecessary columns. Simplify the table, split it into smaller tables, or rewrite the information with headings and lists. Complex tables may require an accessible supplemental file and an on-page summary.

## A heading is missing from navigation

Confirm that the text uses an actual heading level rather than bold or enlarged paragraph text. Check that heading levels are logical.

## A link is read as “click here”

Edit the linked words so they describe the destination, document, or action.

## The saved page differs from the editor

Word-processor markup may still be present. Clean the affected section, reapply the necessary structure, save in Draft Mode, and inspect the result again.

## The source and HTML do not match

Stop publication. Compare names, dates, figures, links, headings, quotations, and legally significant text with the approved source. Correct the HTML and obtain another review when needed.

## You are unsure what to remove

Preserve meaning and ask before guessing. Contact the District Administrator or schoolboard.net Support with the source file, affected page, expected result, and a screenshot when appropriate.
