## Before you begin

**Who should use this guide:** An authorized Group or District Administrator responsible for meeting agendas.

**Required access:** Group Administrator access to the Board or committee group that owns the agenda.

**Recommended starting point:** Use an approved reusable template and work in Draft Mode until review is complete.

## Recommended workflow

1. Open **Drafts & Templates**.
2. Clone the approved template for the meeting type.
3. Update the title, date, time, header, and placeholder content.
4. Actively select the correct Group.
5. Work in Draft Mode: **Private**, **Notifications unchecked**, **Published unchecked**.
6. Save frequently and review the saved agenda.
7. Build or update sections, agenda items, expandable HTML, and attachments.
8. Verify public and private content.
9. Publish, send the intended notifications, and verify the signed-out public view.

!!! tip "Preferred method"
    Clone the appropriate meeting template. Use **Add Content** to build from scratch only when no suitable template exists.

!!! warning "Ask before guessing"
    Stop and ask whenever Group assignment, visibility, publication, notifications, or confidential attachments are unclear. There are no stupid questions.
