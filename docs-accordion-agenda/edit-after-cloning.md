# Edit the Agenda After Cloning

Cloning creates an independent draft with the template's existing structure. Review the complete clone before adding new sections.

## Update meeting information

1. Replace the **Clone of...** title with the meeting title.
2. Update the meeting date and time.
3. Update the Agenda Header and any meeting-specific introductory information.
4. Actively select the correct Board or committee Group, even when it appears highlighted.
5. Confirm Draft Mode: **Private**, **Notifications unchecked**, and **Published unchecked**.
6. Save.

## Complete the template sections

1. Open each existing Accordion Section.
2. Replace template placeholders with the current meeting's content.
3. Use the blank Agenda Items and Expandable HTML components provided by the template.
4. Add a new section only when the meeting needs a section the template does not contain.
5. Remove unused blank sections before publication.
6. Save and review the agenda in Draft Mode.

!!! tip "Blank sections make preparation faster"
    Master templates should contain blank sections for recurring agenda areas. Complete the sections needed for the meeting and remove those that are not needed. This is faster and more consistent than rebuilding the structure for every meeting.

!!! warning "Remove attachments before removing a section"
    If an unused section contains attachments, remove those attachments first and then remove the section. Removing a section deletes all nested content and attachments.
