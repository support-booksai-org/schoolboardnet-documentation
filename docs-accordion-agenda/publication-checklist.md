# Final Publication Checklist

Use this one-page checklist immediately before and after publication.

## Before publication

- [ ] Title, date, time, and Agenda Header are correct.
- [ ] The correct Group was actively selected.
- [ ] Template placeholders and unused blank sections were removed.
- [ ] Sections and Agenda Items are complete and ordered correctly.
- [ ] Public and private Expandable HTML is correctly classified.
- [ ] Every attachment belongs to the intended Agenda Item.
- [ ] Public files are approved for release.
- [ ] Confidential files are under Private Files.
- [ ] Descriptions, Display settings, and attachment order are correct.
- [ ] Replacement files use new filenames and open correctly.
- [ ] The saved draft—not Preview—was reviewed.

## Publication settings

- [ ] Visibility is **Public**.
- [ ] **Published** is selected.
- [ ] **Notifications** is selected only when the notice should be sent now.
- [ ] The correct Group is confirmed again.
- [ ] Revision Text clearly explains any published change.

## After saving

- [ ] Reopen the agenda, clear **Notifications**, and save again.
- [ ] Sign out of the administrator account.
- [ ] Open the agenda from the public Group page.
- [ ] Expand each changed section.
- [ ] Open every changed public file and Expandable HTML item.
- [ ] Confirm no private content is visible.
- [ ] Confirm the independent public-notification account received the notice.
- [ ] Test printing when required. On an iPad or iPhone, use the browser's **Share** button in the new printable window, then select **Print**.

!!! warning "Do not leave Notifications selected"
    Clear Notifications immediately after the intended notice is sent. A later edit or save may otherwise send another notice.

## Group-only revision reminder

After notifying Group members while Visibility is Private:

- [ ] Reopen the agenda.
- [ ] Restore Visibility to **Public**.
- [ ] Leave Notifications unchecked.
- [ ] Save again.
- [ ] Sign out and verify public access.

!!! warning "Do not leave a published agenda Private"
    Complete and verify the final Public save after a Group-only notification.
