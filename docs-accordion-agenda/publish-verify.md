# Publish and Verify an Agenda

Publication is the final step. There is no separate publication screen; after saving with **Published** selected, schoolboard.net displays the saved agenda.

## Complete the final review

Confirm the title, date, time, Agenda Header, Group, section order, Agenda Items, attachments, privacy, and removal of unused template content.

!!! warning "Review the saved draft"
    Do not publish from Preview or unsaved work. Save in Draft Mode and review the saved agenda first.

## Publish and notify the public

1. Edit the approved saved draft.
2. Change **Visibility** to **Public**.
3. Select **Notifications** when the public notice should be sent.
4. Select **Published**.
5. Confirm the correct Group.
6. Save.

![Example public agenda notification.](assets/images/SB-AAC-006-notification-public.png){ .doc-screenshot }

*Figure SB-AAC-006. A public notification links to the agenda.*

!!! important "Notifications are sent when saved"
    Confirm the audience and timing before saving with Notifications selected.

## Verify the signed-out public view

![Published Accordion Agenda with collapsible sections and print controls.](assets/images/SB-AAC-020-published-agenda.png){ .doc-screenshot }

*Figure SB-AAC-020. The published agenda.*

1. Sign out.
2. Open the Group's public page and agenda.
3. Expand every changed section.
4. Open each public file and public Expandable HTML item.
5. Confirm no private item is visible.
6. Test printing when required by district procedure.

!!! tip "Testing on an iPad or iPhone"
    Select **Print Agenda Only** or **Print Full Packet**. After the printable agenda opens in a new browser window, select the browser's **Share** button, then select **Print**.

!!! important "Preview is not the public view"
    Only a signed-out check verifies what an anonymous visitor can access.

## Confirm public notification delivery

Subscribe to public notifications using a personal or otherwise independent email address. Receiving the notice and opening its link independently confirms delivery and public access.

If the notice does not arrive, verify settings before assuming subscribers received it.
