# Public and Private Attachments

Attachments belong beneath the **Agenda Item** they support. Place every file in the correct public or private area before saving, and review the saved draft before publication.

## Understand attachment access

- **Public Files** are available to everyone after the agenda is published.
- **Private Files** are available only to authorized, signed-in members of the assigned Group.

![Expanded agenda showing public and private content.](assets/images/SB-AAC-014-completed-agenda-item-expanded.png){ .doc-screenshot }

*Figure SB-AAC-014. Public and private components beneath an Agenda Item.*

### Numbered published components

1. **Accordion Section** — the collapsible agenda heading.
2. **Agenda Item** — the meeting text within the section.
3. **Public File** — an attachment available to everyone.
4. **Private File** — an attachment available only to authorized Group members.
5. **Public Expandable HTML** — accessible on-page content available to everyone.
6. **Private Expandable HTML** — accessible on-page content restricted to authorized Group members.

!!! warning "Private means restricted"
    Do not place confidential material in **Public Files**. Before publishing, verify each attachment's location and then check the signed-out public view.

## Add a public attachment

1. Edit the Accordion Section and the appropriate Agenda Item.
2. Expand **Public Files**.
3. Under **Add a new file**, select **Choose Files**.
4. Select the approved file.
5. Enter a clear **Description**. The description may become the visible link label, so describe the document rather than repeating a cryptic filename.
6. Leave **Display** selected when the attachment should appear with the Agenda Item.
7. Save the agenda in Draft Mode.

Example descriptions include:

- **High School Design v6.4**
- **Proposed 2026–27 Budget**
- **Policy 2410 — First Reading**

!!! tip "Use meaningful descriptions"
    A descriptive link is easier for board members, the public, and assistive-technology users to understand than a filename such as `document-final-3.pdf`.

## Add a private attachment

1. Edit the appropriate Agenda Item.
2. Expand **Private Files**.
3. Under **Add a new file**, select **Choose Files**.
4. Select the confidential file.
5. Enter a clear description.
6. Save the agenda in Draft Mode.

Private attachments are intended only for authorized Group members. They are not a substitute for confirming that the agenda is assigned to the correct Group.

!!! important "Verify Group assignment"
    Private access depends on the agenda's Group assignment. Actively select the intended Group after cloning and confirm it again before publication.

## Display or hide an attachment

The **Display** checkbox controls whether an uploaded attachment appears with the Agenda Item.

![Existing public attachment with Display and Remove controls.](assets/images/SB-AAC-018-replacing-attachment-step-1.png){ .doc-screenshot }

*Figure SB-AAC-018A. Existing attachment controls.*

1. **Display** — selected when the attachment should appear.
2. **Remove** — removes the attachment when the agenda is saved.

Clear **Display** only when the file should remain attached to the agenda record but should not be shown. Do not use Display as a privacy control; public versus private placement controls access.

## Replace an attachment safely

When a file changes, schoolboard.net recommends removing the old attachment and uploading the replacement with a **new filename**. A new filename helps browsers and search indexes recognize the replacement as a new file rather than continuing to use a cached copy.

1. Edit the Agenda Item containing the old file.
2. Select **Remove** beside the old attachment.
3. Upload the approved replacement in the same public or private file area.
4. Give the replacement a new filename, such as `high-school-design-v2.pdf` instead of reusing `high-school-design.pdf`.
5. Enter or confirm the descriptive link label.
6. Confirm **Display** is selected.
7. Save the agenda in Draft Mode.
8. Reopen the saved draft and open the replacement file to verify it.

![Replacement attachment with a new filename and confirmed description.](assets/images/SB-AAC-018-replacing-attachment-step-2.png){ .doc-screenshot }

*Figure SB-AAC-018B. Upload the replacement under a new filename and retain a meaningful description.*

!!! warning "Verify before publishing"
    Open the saved replacement rather than relying on its name. Confirm that it is the approved version, opens correctly, and remains under the intended Agenda Item and access level.

## Move a file between public and private

If a file was uploaded to the wrong area, it does not need to be removed and uploaded again.

![Public and private attachments with switch controls.](assets/images/SB-AAC-019-switch-public-private.png){ .doc-screenshot }

*Figure SB-AAC-019. Move an attachment to the correct access level when the agenda is saved.*

1. **Switch to private** — moves the public attachment into **Private Files** when the agenda is saved.
2. **Switch to public** — moves the private attachment into **Public Files** when the agenda is saved.

### Move public to private

1. Locate the file under **Public Files**.
2. Select **Switch to private**.
3. Save the agenda.
4. Reopen the Agenda Item and confirm the file now appears under **Private Files**.

### Move private to public

1. Confirm that the file is approved for public release.
2. Locate it under **Private Files**.
3. Select **Switch to public**.
4. Save the agenda.
5. Reopen the Agenda Item and confirm the file now appears under **Public Files**.

!!! warning "Public release requires deliberate review"
    **Switch to public** changes who may access the attachment. Confirm authorization and the file's contents before selecting it. After publication, sign out and verify the public view.

## Reorder attachments

Use the drag handle beside a file to change its order within the public or private file area. Save the agenda and review the saved order.

Keep related files together and place them in the same sequence in which they are discussed in the Agenda Item.

## Attachment review checklist

Before publishing, confirm:

- every attachment belongs to the intended Agenda Item;
- every confidential file is under **Private Files**;
- every public file is approved for public release;
- descriptions are meaningful and unique;
- obsolete files have been removed;
- replacement files use new filenames and open correctly;
- **Display** is selected for files that should appear;
- attachment order is correct; and
- the signed-out public view contains only the intended public material.

!!! tip "Independent public-notification check"
    Group Administrators should subscribe to public notifications using a personal or otherwise independent email address. Receiving the notice and opening its links provides confirmation that the public notification was distributed and the published material can be reached.
