# Accordion Sections and Agenda Items

Build an agenda one **Accordion Section** at a time. Each section contains one or more **Agenda Items**.

## Add an Accordion Section

1. Open the agenda for editing.
2. Go to the location where the section should appear.
3. Select **Add Accordion Section**.

![Add Accordion Section control.](assets/images/SB-AAC-011-add-accordian-section-button.png){ .doc-screenshot }

*Figure SB-AAC-011A. Add an Accordion Section to the agenda.*

4. Enter a concise **Section Title**.
5. Add the Agenda Item content beneath it.
6. Add supporting material when needed.

![New Accordion Section with a title, Agenda Item, and file areas.](assets/images/SB-AAC-011-create-accordion-section.png){ .doc-screenshot }

*Figure SB-AAC-011B. Complete the new Accordion Section.*

### Numbered section fields

1. **Section Title** — the heading visitors select to expand or collapse this part of the agenda.
2. **Agenda Item content** — the matters, reports, motions, resolutions, or discussion text.
3. **Public Files** — attachments available to everyone after publication.
4. **Private Files** — attachments available only to authorized Group members.

![Saved Building Committee Accordion Section.](assets/images/SB-AAC-011-view-accordion-section.png){ .doc-screenshot }

*Figure SB-AAC-011C. A saved Accordion Section.*

## Edit an Agenda Item

Select **Edit** beside the section. The editor displays the section title and its nested Agenda Items.

![Accordion Section editor showing nested Agenda Items and the Add menu.](assets/images/SB-AAC-003-clone-me-accordion-section.png){ .doc-screenshot }

*Figure SB-AAC-003. Edit the section and add nested content.*

The **Add Agenda Item(s)** menu lets you add an Agenda Item or Expandable HTML. An Agenda Item may contain several headings or paragraphs when they belong to the same matter. Create a separate Agenda Item when material needs its own attachments or independent management.

![Agenda Item editor identifying its primary fields.](assets/images/SB-AAC-004-clone-me-edit-agenda-item.png){ .doc-screenshot }

*Figure SB-AAC-004. Edit an Agenda Item and its supporting files.*

### Numbered Agenda Item fields

1. **Section Title** — identifies the parent Accordion Section.
2. **Content** — contains headings, descriptions, motions, resolutions, reports, or discussion text.
3. **Public Files** — attachments available to everyone after publication.
4. **Private Files** — attachments restricted to authorized Group members.

Keep **Text format** set to the district's approved format unless schoolboard.net Support directs otherwise.

!!! important "Supporting material belongs to the Agenda Item"
    Public Files, Private Files, Public Expandable HTML, and Private Expandable HTML belong beneath an Agenda Item. Verify their position before saving.
