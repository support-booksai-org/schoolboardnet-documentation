# Accordion Agenda Quick Start

Use this one-page workflow for normal meeting preparation.

## 1. Clone

- Open **Drafts & Templates**.
- Clone the approved meeting-type template.
- Rename **Clone of...**.

## 2. Confirm the draft

- Update title, date, time, and Agenda Header.
- Actively select the correct Group.
- Keep **Private**, **Notifications unchecked**, and **Published unchecked**.
- Save.

## 3. Complete the agenda

- Replace template placeholders.
- Complete the blank recurring sections needed for this meeting.
- Add or edit Agenda Items and Expandable HTML.
- Remove unused blank sections.

## 4. Add supporting material

- Put approved public files under Public Files.
- Put confidential files under Private Files.
- Use meaningful descriptions.
- Open saved attachments to verify them.

## 5. Review

- Review the saved draft, not just Preview.
- Confirm section order, content, privacy, attachments, and Group.
- Ask another authorized reviewer when district procedure requires it.

## 6. Publish

- Set Visibility to Public.
- Select Notifications when the public notice should be sent.
- Select Published.
- Confirm Group and save.

## 7. Verify

- Sign out.
- Open the public Group page and agenda.
- Test changed sections and public links.
- Confirm no private material appears.
- Confirm the independent public-notification account received the notice.

!!! warning "Stop and ask"
    Ask before saving whenever Group, privacy, publication, notifications, or confidential material is unclear.
