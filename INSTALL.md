# Install — Board Member Review Drop

Copy the `docs/` folder from this package into the root of your `schoolboardnet-docs` repository.

This package adds:

- Board Member Quick Start Guide
- Board Member Guide
- Reviewer notes
- Reviewer email draft
- Screenshot index for the Board Member screenshots
- MkDocs navigation snippet

## Build and review locally

```bash
cd "/Volumes/Current Projects/SBN/schoolboardnet-llc/schoolboardnet-docs"
./scripts/serve.sh
```

Open:

```text
http://127.0.0.1:8000
```

## Suggested commit message

```text
Add Board Member review guide
```

## Screenshot requirement

This package assumes the approved screenshots are located here:

```text
docs/assets/screenshots/approved/board-members/
```
