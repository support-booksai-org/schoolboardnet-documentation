## Overview

schoolboard.net helps districts create, publish, and maintain accessible board meeting materials. The platform is designed to support structured HTML content, searchable agendas, notifications, revisions, public access, and private access controls.

## When to Use This Article

Use this article when you are new to schoolboard.net or need a general introduction to how the platform organizes board meeting content.

## Key Concepts

The primary workflow is the **Accordion Agenda**. An Accordion Agenda may include Agenda Sections, Agenda Items, Nested Agenda Items, Expandable HTML, Public Files, Private Files, Notifications, and Revisions.

## Best Practices

- Use structured HTML when possible instead of relying only on PDFs.
- Use descriptive titles and agenda labels.
- Review permissions before publishing private content.
- Review AI-generated HTML before importing it.

## Accessibility Notes

Structured HTML can improve navigation for screen reader users and make board materials easier to search, read, and update.
