# Accessibility Standards

## Purpose

The schoolboard.net Documentation Suite should support WCAG 2.1 AA principles for published HTML and PDF output.

## Core Requirements

- Use one logical H1 per page or article.
- Use headings in order.
- Use descriptive links.
- Provide alt text for meaningful images.
- Avoid using color as the only way to communicate meaning.
- Use simple tables with clear headers.
- Avoid scanned text whenever possible.
- Explain all screenshot actions in text.
- Use plain language.

## PDF Output Requirements

Final PDF exports should include:

- Tagged PDF structure
- Logical reading order
- Bookmarks
- Descriptive document title
- Alt text for meaningful images
- Hyperlinked table of contents
- Accessible tables where practical

## HTML Output Requirements

Knowledge Base articles should include:

- Semantic headings
- Meaningful link text
- Valid lists
- Accessible tables
- Descriptive image alt text
- Keyboard-accessible content
