# Screenshot Standards

## Source Site

Screenshots should be taken from:

> demo10.schoolboard.net

unless a chapter specifically identifies a different source.

## Naming Convention

Use this format:

```text
SB-[AREA]-[NUMBER]-[short-description].png
```

Examples:

```text
SB-ADM-001-dashboard.png
SB-USR-002-add-user-form.png
SB-AGD-014-expandable-html.png
```

## Screenshot Folders

- `assets/screenshots/raw/` — Original unedited captures
- `assets/screenshots/annotated/` — Screenshots with arrows, callouts, or highlights
- `assets/screenshots/approved/` — Final screenshots approved for publication

## Alt Text

Every screenshot must include alt text.

Good alt text:

> Administrator dashboard showing the main navigation menu and content management options.

Poor alt text:

> Screenshot of dashboard.

## Annotation Rules

Use annotations sparingly. Highlight the action the user must take.

Acceptable annotations:

- Numbered callouts
- Arrows
- Rectangular highlights
- Short labels

Avoid:

- Decorative effects
- Excessive arrows
- Text that duplicates the entire procedure

## Accessibility Notes

Do not rely on screenshots alone. Every action shown in a screenshot must also be explained in text.
