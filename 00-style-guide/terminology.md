# Terminology Guide

**Status:** Draft  
**Version:** 1.0.0-draft  
**Owner:** schoolboardnet, LLC  

## Purpose

This guide defines official terminology for schoolboard.net documentation. Use these terms consistently in manuals, Knowledge Base articles, support materials, release notes, and AI training content.

## Product Name

Use:

> schoolboard.net

Do not use:

- SchoolBoard.net
- SchoolBoardNet
- Schoolboard.net
- schoolboardNet

## Company Name

Use:

> schoolboardnet, LLC

## Core Terms

| Preferred Term | Definition | Notes |
|---|---|---|
| Accordion Agenda | The primary agenda format used by schoolboard.net. | Preferred over Event or Book for new documentation. |
| Agenda Section | A major section within an Accordion Agenda. | Example: Consent Agenda, Reports, Action Items. |
| Agenda Item | A specific item within an Agenda Section. | May contain text, files, or Expandable HTML. |
| Nested Agenda Item | An Agenda Item placed under another Agenda Item. | Use for subitems or supporting details. |
| Expandable HTML | Accessible HTML content that expands within an agenda. | Expand Text should normally begin with “Read …”. |
| Expand Text | The visible text users select to open Expandable HTML content. | Should be descriptive and screen-reader friendly. |
| Public File | A file available to the public. | Use only when HTML is not practical. |
| Private File | A file restricted to authorized users or groups. | Document carefully because permissions matter. |
| Notification | A message sent to users or the public. | May relate to publishing or revisions. |
| Revision | A saved change to content. | Used to track and communicate updates. |
| Publish | Make content available to the intended audience. | Use instead of “post” when referring to the platform action. |
| Administrator | A user with administrative access. | Avoid “admin” in formal documentation unless referring to a path or role label. |
| Board Clerk | A district staff member responsible for board meeting materials. | Common primary audience. |
| Group | A collection of users used for access control or organization. | Use with Group Membership and Permissions. |
| Permission | A setting that controls what a user or group can access or do. | Be precise. |
| Knowledge Base | The searchable documentation area inside schoolboard.net. | Also supports BooksAI training. |
| AI-assisted HTML Conversion | Using AI tools to help convert Word, Google Docs, or PDF content into accessible HTML. | Always requires human review. |

## Terms to Avoid or Limit

| Avoid | Use Instead |
|---|---|
| Click here | Descriptive link text |
| Post an agenda | Publish an agenda |
| Admin | Administrator |
| Upload the agenda as a PDF | Convert agenda content to accessible HTML where practical |
| Blind user | Screen reader user, user who is blind |
| Handicapped | Disabled, people with disabilities |

## Deprecated or Lower-Priority Features

The documentation should focus on Accordion Agendas as the primary workflow. Event and Book workflows may be documented only where needed for legacy support or technical reference.
