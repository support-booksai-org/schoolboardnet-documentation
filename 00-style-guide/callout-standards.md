# Callout Standards

Use callouts to highlight important information without interrupting the procedure.

## Tip

Use for helpful shortcuts or optional guidance.

```markdown
> **Tip:** You can use the search field to find an existing agenda quickly.
```

## Best Practice

Use for recommended workflows.

```markdown
> **Best Practice:** Use Expandable HTML instead of uploading a PDF whenever the content can be converted cleanly.
```

## Accessibility

Use for WCAG-related guidance.

```markdown
> **Accessibility:** Use descriptive Expand Text so screen reader users understand what will open before selecting it.
```

## AI Tip

Use for AI-assisted conversion guidance.

```markdown
> **AI Tip:** Ask Claude or Gemini to preserve headings, lists, tables, and links when converting agenda attachments to HTML.
```

## Administrator Note

Use for advanced or permission-related information.

```markdown
> **Administrator Note:** Private Files should be tested with a non-administrator account before publication.
```

## Warning

Use for actions that may cause errors, confusion, or unintended public disclosure.

```markdown
> **Warning:** Do not attach confidential material as a Public File.
```

## Troubleshooting

Use for problem/cause/resolution guidance.

```markdown
> **Troubleshooting:** If the notification was not received, confirm that the user account has a valid email address and that notifications were selected during publishing.
```
