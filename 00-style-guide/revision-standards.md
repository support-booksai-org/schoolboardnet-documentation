# Revision Standards

## Purpose

This guide defines how schoolboard.net documentation revisions are tracked.

## Version Format

Use semantic versioning where practical:

```text
MAJOR.MINOR.PATCH-status
```

Example:

```text
1.0.0-draft
1.0.0-review
1.0.0-published
```

## Revision History Table

Each chapter should include a revision history table.

| Date | Version | Author | Description |
|---|---|---|---|
| 2026-06-29 | 1.0.0-draft | schoolboardnet, LLC | Initial draft |

## Approval Status

Use these values:

- Draft
- Review
- Approved
- Published
- Archived

## Documentation Change Types

| Type | Meaning |
|---|---|
| New | New chapter, section, or article |
| Update | Revised existing content |
| Correction | Fixed an error |
| Screenshot | Updated screenshots |
| Accessibility | Improved accessibility guidance or output |
| Release | Updated for a software release |
