# Volume 0 — Documentation Style Guide

This folder contains the standards used to create and maintain the schoolboard.net Documentation Suite.

## Files

- `writing-style.md` — Voice, tone, and writing rules
- `terminology.md` — Official schoolboard.net vocabulary
- `screenshot-standards.md` — Screenshot capture, naming, annotation, and alt text standards
- `callout-standards.md` — Tip, warning, accessibility, AI tip, and administrator note formats
- `accessibility-standards.md` — Documentation accessibility requirements
- `revision-standards.md` — Versioning, revision history, and approval workflow
