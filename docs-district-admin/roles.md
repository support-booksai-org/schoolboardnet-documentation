# Roles and access

Review site roles and group memberships separately. Use the least access required for the person's assignment.

## Role guidance

- **District Admin** is for approved district-level administration. Only schoolboard.net Support can add, delete, or modify a role assignment, including removing the role from an account.
- **Group Admin** is for approved group-management functions allowed by site configuration.
- An ordinary Board Member generally needs the correct group membership, not a site-wide administrator role.

!!! danger "District Administrator role requests must be emailed"
    A district user, Group Administrator, or District Administrator cannot add, delete, or modify a **District Administrator** role assignment. Send every request in writing by email to schoolboard.net Support. Include the district site, person's name, username or email address, requested change, effective date, and the authorized district requester.

## Recommended number of District Administrators

There is no system limit on the number of District Administrators. For clearer accountability and reduced security risk, schoolboard.net recommends limiting each district to **two or three District Administrators**.

Review the list when responsibilities change. Email schoolboard.net Support promptly when the role must be added, removed, or modified.

## Least-access sequence

1. Start with the ordinary user account.
2. Add only required group memberships.
3. Add Group Admin only when the person must manage the group.
4. When District Administrator access is required, obtain district approval and email the written request to schoolboard.net Support.
5. Test with the user's own account; never share administrator credentials.

!!! note "Group Administrator changes"
    Follow the approved group-membership workflow for Group Administrator access. The schoolboard.net Support-only restriction applies specifically to the District Administrator role.
