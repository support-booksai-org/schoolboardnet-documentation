# Security Policies

These procedures provide a written authorization trail for district-wide administrative access.

## District Administrator accounts

Only schoolboard.net Support can add, remove, or modify District Administrator access. Submit every request by email from an authorized district representative. Include the district and site, administrator name, username or email, requested action, effective date, and authorized requester.

schoolboard.net recommends maintaining two or three District Administrators for continuity while keeping district-wide access limited.

## ATM (Administrative Team)

Every site is provisioned with an **ATM (Administrative Team)** group using the **No Private File Access** group type.

- Administrators do not need to create this group.
- During setup, schoolboard.net assigns the designated District Administrator as a Group Administrator of ATM.
- Requests to change ATM administration or membership must be submitted by email to schoolboard.net Support for security documentation.
- ATM members may review shared content but cannot view private attachments.

!!! warning "Do not create another ATM group"
    Use the provisioned ATM group. Email schoolboard.net Support when its administration or membership must change.

## Group types are permanent

A group's type cannot be changed after creation. If the wrong type is selected, create a new group using the correct type and move content according to an approved plan. Always confirm the intended type before saving a new group.
