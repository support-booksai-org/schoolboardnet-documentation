# Conventions Used in This Guide

This guide uses consistent information boxes to distinguish instructions from operational and security guidance.

!!! tip "Tip or Best Practice"
    A recommended method that improves consistency or reduces avoidable work.

!!! note "Note"
    Helpful background information or a related detail.

!!! important "Important"
    A step that deserves particular attention to avoid an access or content problem.

!!! warning "Warning or Security Restriction"
    A security, privacy, or access risk. Stop and verify authorization before continuing.

## Using this guide on a phone or tablet

1. Select **☰ Topics** in the upper-left corner to open the guide menu.
2. Select a topic.
3. Select the page-outline icon on the right side of the topic title to open the page **Table of Contents**.
4. Select a heading to move directly to that section.

!!! tip "Questions are encouraged"
    If a direction, permission, or request is unclear, ask before continuing. There are no stupid questions.
