# schoolboard.net Documentation Workbench

This folder contains the Keyboard Maestro setup for consistent schoolboard.net screenshot capture using Dia and Snagit.

## Standard

- Browser: Dia on macOS
- Requested window size: 1600 × 1200
- Position: upper left
- Typical actual visible size: about 1588 × 1146, depending on macOS display scaling
- Browser zoom: 100%
- Capture tool: Snagit
- Screenshot source folder: `assets/source/snagx`

## Installed location

Place this folder at:

```text
schoolboardnet-docs/tools/keyboard-maestro/
```

## Capture folders

Screenshots should go in:

```text
schoolboardnet-docs/assets/source/snagx/
```

Capture session logs should go in:

```text
schoolboardnet-docs/docs/capture-sessions/
```

## Main macro

Import:

```text
macros/schoolboardnet-documentation-workbench.kmmacros
```

Main hotkey:

```text
Control + Option + Command + D
```
