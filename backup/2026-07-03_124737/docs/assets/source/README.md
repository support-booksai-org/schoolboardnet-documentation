# Source Assets

This folder contains the editable source files used to create images and graphics for the schoolboard.net Documentation Suite.

These files are not published directly.

They are the master source used to generate the PNG files found in the **assets/screenshots** folders.

---

## Contents

- Snagit (.snagx)
- Future diagrams
- Future vector artwork

---

## Editing Rules

Always edit the source file.

Never edit exported PNG files.

After making changes:

1. Save the updated source file.
2. Export a new PNG.
3. Increment the screenshot version if necessary.
4. Replace the PNG in the appropriate screenshot folder.
5. Update the Screenshot Inventory.
