# What is schoolboard.net?

## Quick Summary

schoolboard.net is a web-based system for school board meeting materials.

It helps districts organize agendas, supporting documents, public files, private files, notifications, revisions, search, and printing.

## The Simple Explanation

Think of schoolboard.net as a digital board meeting binder.

Instead of printing packets or posting many separate PDF files, the district can build an online agenda.

Each agenda can include:

- Meeting information
- Agenda sections
- Agenda items
- Supporting text
- Public files
- Private files
- Links
- Notifications
- Revision history

## Why Districts Use It

Districts use schoolboard.net to make board materials easier to manage and easier to use.

A good agenda system should help people answer simple questions quickly:

- What meeting is this?
- What items will be discussed?
- What documents support each item?
- What changed since the last version?
- What can the public see?
- What is private?
- How do I search older records?

## HTML First, Not PDF Only

schoolboard.net is designed around accessible web content.

That means key information should be placed directly on the web page whenever practical.

PDF files may still be used. But they should not be the only way important information is shared.

## Why That Matters

Web content is often easier to:

- Read on phones.
- Search.
- Update.
- Print.
- Use with screen readers.
- Convert for future systems.
- Index for AI and search tools.

## Best Practice

Use HTML for agenda text whenever practical.

Use files when a separate document is truly needed.

## Administrator Note

Public files and private files should be named carefully.

Avoid spaces and punctuation other than underscores or hyphens. Use version numbers in filenames, such as `_v1` or `_01`. Use the Description field for the friendly name shown on the agenda.
