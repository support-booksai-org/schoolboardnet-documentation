# Getting Help

## Quick Summary

Use this page when you are not sure what to do next.

Most questions can be solved by checking your role, your group, the item status, or the documentation.

## Start with the Simple Checks

Before asking for help, check these items:

- Are you signed in?
- Are you using the correct user account?
- Are you in the correct group?
- Do you have permission to complete the task?
- Has the item been saved?
- Has the agenda been published?
- Are you viewing the public version or the administrator version?

## Common Help Topics

Common questions include:

- I cannot sign in.
- I cannot see an agenda.
- I cannot edit an item.
- I cannot upload a file.
- A private file is not visible.
- A notification did not send.
- Search results are not showing what I expected.
- A Word document pasted with messy formatting.

## When to Contact Your District Administrator

Contact your District Administrator if:

- You need access.
- Your password needs to be reset.
- You cannot see a group.
- You need a new permission.
- You are not sure whether a file should be public or private.

## When to Contact schoolboard.net Support

Contact schoolboard.net support if:

- The site shows an error.
- A feature does not work as expected.
- A notification problem cannot be solved locally.
- Search or indexing appears incorrect.
- Private file access does not match permissions.
- You need help with a migration or setup issue.

## Best Practice

When asking for help, include:

- What you were trying to do.
- The page you were on.
- The name of the agenda or item.
- The group name.
- A screenshot if possible.
- The exact error message, if any.

## Administrator Note

Many support questions are really permission questions.

Before reporting a problem, check the user's role, group membership, and content access.
