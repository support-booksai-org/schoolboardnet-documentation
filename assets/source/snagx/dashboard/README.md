# Dashboard / Home Screenshot Source

## Purpose

This folder stores the editable Snagit source file for the **Dashboard / Home** screenshots.

## Source File

`dashboard-home.snagx`

## PNG Exports

Export finished PNG files to:

`assets/screenshots/dashboard`

Suggested exports:

- `dashboard-home.png`
- `dashboard-login.png`
- `dashboard-search.png`
- `dashboard-upcoming-events.png`
- `dashboard-past-events.png`

## Workflow

1. Capture the base screen in Snagit.
2. Save the editable source as `dashboard-home.snagx`.
3. Duplicate/annotate inside Snagit as needed.
4. Export final PNG files using the names above.
5. Run sbDocs inventory/validation before publishing.
