# Release Notes — Board Member Review Drop

## Purpose

This release provides a polished first review draft for the **Board Member Guide** and **Board Member Quick Start Guide**.

The goal is to provide enough completed documentation for user review before the larger Knowledge Base is expanded.

## Included

- Board Member Quick Start Guide
- Board Member Guide landing page
- Login instructions
- Password reset instructions
- Finding upcoming meetings
- Opening an accordion agenda
- Reading public and board member attachments
- Printing and saving as PDF
- Search instructions
- My Account overview
- FAQ
- Reviewer checklist
- Reviewer email draft

## Review focus

Reviewers should focus on:

- clarity
- order of topics
- whether the screenshots are helpful
- missing first-time user questions
- whether the guide feels usable without training

## Not included yet

- Group Administrator Guide
- District Administrator Guide
- Agenda creation procedures
- User management procedures
- Internal technical documentation
