## Purpose

This chapter introduces schoolboard.net and explains how this guide should be used. It also explains the documentation conventions used throughout the Administrator Training Guide.

schoolboard.net is designed to help districts create, publish, and maintain board meeting materials in a way that is accessible, searchable, organized, and easier to manage over time.

## Prerequisites

Before using this guide, you should have:

- A schoolboard.net user account.
- Access to your district's schoolboard.net site.
- The appropriate permissions for your role.
- A basic understanding of how your district prepares board agendas and supporting materials.

## Overview

The Administrator Training Guide is written for the people who manage board meeting content. This may include board clerks, administrative assistants, district administrators, and IT staff.

The guide explains not only how to use schoolboard.net, but also why certain workflows are recommended. This is especially important for accessibility. A district can publish information online, but that information is not truly useful unless people can read it, search it, navigate it, and understand it.

## Accessibility-First Publishing

schoolboard.net is designed around accessibility-first publishing. The platform encourages districts to use structured HTML content instead of relying only on PDF attachments.

Accessible HTML provides several advantages:

- It is easier for screen reader users to navigate.
- It can be searched more effectively.
- It works better on phones and tablets.
- It can be updated without replacing an entire file.
- It supports cleaner long-term public records.
- It reduces dependence on inaccessible or poorly tagged PDFs.

> **Accessibility:** When practical, agenda content should be placed in structured HTML rather than attached only as a PDF. HTML headings, lists, links, and tables can make content easier to navigate for all users.

## How schoolboard.net Organizes Board Content

The primary content workflow is the **Accordion Agenda**.

An Accordion Agenda may include:

- Agenda Sections
- Agenda Items
- Nested Agenda Items
- Expandable HTML
- Public Files
- Private Files
- Notifications
- Revisions

Each part has a specific purpose. Later chapters explain how to create and manage each one.

## Documentation Conventions

This guide uses consistent formatting to help you follow instructions.

| Convention | Meaning |
|---|---|
| **Bold text** | A button, field, tab, menu item, or screen label |

## Example Callouts

> **Tip:** If you are new to schoolboard.net, begin with the chapters on Logging In, Dashboard, Users, Groups, and Accordion Agendas.

> **Best Practice:** Use Expandable HTML for agenda materials that can be converted cleanly from Word, Google Docs, or another structured source.

> **Warning:** Do not publish confidential content as a Public File. Always verify file visibility before publishing.

> **AI Tip:** AI tools such as Claude or Gemini can help convert Word or Google Docs content into HTML, but the result should always be reviewed before it is published.

## Administrator Notes

- Permissions determine what a user can see and do.
- Private content should always be tested with a non-administrator account.
- Revisions should be used carefully when changes need to be tracked or communicated.
- Notifications should be reviewed before sending to the public or board members.

## Best Practices

- Create board materials in Word or Google Docs using proper headings and lists.
- Convert agenda content to accessible HTML whenever practical.
- Use descriptive Expand Text that begins with “Read …” when appropriate.
- Review all AI-generated HTML before importing it into schoolboard.net.
- Test public and private access before publishing important materials.
- Keep agenda titles, section names, and item labels clear and consistent.

## Troubleshooting

| Problem | Possible Cause | Resolution |
|---|---|---|
| You cannot see an administrator option. | Your account may not have the required permission. | Contact a site administrator or support representative. |
| A user cannot access private content. | The user may not belong to the correct group. | Review the user's group membership and permissions. |
| Agenda content appears poorly formatted. | Content may have been pasted from Word with extra formatting. | Clean the HTML or use the recommended Word-to-HTML workflow. |
| A notification was not received. | The recipient email address may be missing or incorrect. | Confirm the user's account email address and notification settings. |

## Frequently Asked Questions

### Is schoolboard.net only for publishing agendas?

No. schoolboard.net is designed to help districts manage board meeting materials, supporting documents, accessibility workflows, search, printing, notifications, revisions, and public access.

### Should districts stop using PDFs completely?

Not necessarily. PDFs may still be needed in some situations. However, when content can be converted to accessible HTML, HTML is usually easier to search, navigate, update, and read with assistive technology.

### Can AI-generated HTML be published directly?

AI-generated HTML should be reviewed before publication. Headings, links, tables, lists, and accessibility labels should be checked for accuracy.
