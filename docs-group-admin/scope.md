# What Group Administrators can do

A Group Administrator manages membership and meeting agenda content in an assigned group.

## Included in this guide

- View the group's current members.
- Add an existing user to the group.
- Remove a user from the group.
- Verify that a membership change was completed.
- Create and update agendas for the assigned group.
- Add approved agenda attachments and confirm that they open correctly.

## Contact a District Administrator for

- Creating a user account.
- Changing a username, email address, or password.
- Assigning district-level roles or permissions.
- Creating, renaming, or changing the type of a group.
- Blocking, restoring, or cancelling a user account.
- Resolving access that remains incorrect after the group membership is verified.

!!! warning "Membership is not the user account"
    Removing someone from a group does not block or delete the person's schoolboard.net account. It removes only that group membership.

!!! important "Agenda instructions"
    Agenda creation is available to both Group Administrators and District Administrators. Use the shared [Accordion Agenda Guide](https://docs.schoolboard.net/accordion-agenda/) for the complete workflow.
