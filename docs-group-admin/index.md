# Group Administrator Quick Start

Use this guide to manage membership and agenda content in the group or groups assigned to you.

On a smaller screen, select **☰ Topics** to open the documentation menu.

## Five-step workflow

1. Open the correct group and select **Members**.
2. Review the list before making a change.
3. Add an existing user or remove a membership.
4. Return to the Members list and verify the result.
5. When preparing a meeting, add the agenda and its approved attachments, then use the [Accordion Agenda Guide](https://docs.schoolboard.net/accordion-agenda/) for the complete procedure.

!!! important "Account creation"
    A Group Administrator adds an existing schoolboard.net user to a group. If the user does not already have an account, contact a District Administrator.

## Before you finish

- Confirm that you changed the correct group.
- Confirm the username before adding or removing membership.
- Verify the Members list after saving.
- Preview the agenda and confirm every attachment opens correctly before publishing.
- Sign out when working on a shared device.
