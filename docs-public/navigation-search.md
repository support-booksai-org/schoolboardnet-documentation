# Navigation and search

## Use the primary navigation

The navigation may include **Home**, **School Board**, **Committees**, **Policy Manual**, **Accessibility Statement**, and **Support**. Available items can vary by district.

![Public navigation with Home, School Board, Committees, Policy Manual, Accessibility Statement, and Support.](assets/screenshots/SB-PUB-002-primary-navigation-v01.png){ .doc-screenshot }

## Search the site

1. Enter a keyword or phrase in **Search by keyword or phrase**.
2. Select **Search**.
3. Review the result title, excerpt, and date.
4. Open the result and confirm that it belongs to the meeting you need.

![Search by keyword or phrase field and Search button.](assets/screenshots/SB-PUB-003-site-search-v01.png){ .doc-screenshot }

## Refine a search

Use **Advanced search** to find any word, an exact phrase, or to exclude words. Available content-type and language filters appear below the keyword fields.

![Public search results with Advanced search filters and a matching meeting result.](assets/screenshots/SB-PUB-010-public-search-results-v01.png){ .doc-screenshot }
