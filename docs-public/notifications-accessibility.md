# Notifications and accessibility

## Subscribe to notifications

Select **Click here to sign Up for Notifications** when the district offers public email updates. A notification tells you that content was published or changed; the live district site remains the current version.

![Public notification signup link on the district home page.](assets/screenshots/SB-PUB-012-notification-signup-v01.png){ .doc-screenshot }

## Use keyboard and accessibility features

- Press **Tab** or **Shift+Tab** to move between controls.
- Press **Enter** to open a link.
- Press **Enter** or **Space** to operate agenda headings and buttons.
- Use a visible skip link to move directly to the main page region when it appears.
- Use the district's **Accessibility Statement** for accessibility and accommodation contact information.

![Public home page displaying a visible Skip to header link during keyboard navigation.](assets/screenshots/SB-PUB-014-keyboard-focus-v01.png){ .doc-screenshot }

## Report a barrier

Include the meeting title, date, page address, browser, assistive technology, link or control label, and what happened.
